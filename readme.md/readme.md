# Elderly Fall and Health Monitoring Device

Overview
This project is an IoT based health monitoring system using ESP8266.

It can:
- Detect falls using ADXL345
- Monitor temperature using LM35
- Display data on LCD
- Send data through WiFi
- Trigger buzzer alerts during emergencies

 Components Used
- ESP8266
- ADXL345 Accelerometer
- LM35 Temperature Sensor
- I2C LCD Display
- Buzzer

 Features
- Fall Detection
- Temperature Monitoring
- WiFi Monitoring
- LCD Display
- Emergency Alert System

 Technologies Used
- Arduino IDE
- Embedded C
- ESP8266 WiFi
